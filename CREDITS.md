## Voice cheers and fallback

English, Hindi and Telugu cheers use the device/browser Speech Synthesis engine, when available. The selected device voice can vary by operating system and browser; no third-party voice recording is bundled. If Howler or an OGG sample cannot play, SoundManager falls back to a very short Web Audio tone and keeps the application usable.

## Format note

This bundled pack contains OGG originals only; matching MP3 encodings and separately recorded female voice clips are not bundled in this pass. The manager is centralized so MP3 sources or licensed voice clips can be added later in `sounds/sound-map.js` without editing application components.
